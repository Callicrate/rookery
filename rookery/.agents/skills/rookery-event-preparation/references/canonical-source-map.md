# Canonical Rookery Sources

Paths below are relative to the installed Rookery root.

| Source | Use |
| --- | --- |
| `README.md` | Supported operator surface and launch prerequisites. |
| `.env.example` | Reviewed catalog for the single operator-edited `.env`. |
| `docs/operator.md` | Launch gate, pure status behavior, and configuration ownership. |
| `docs/preparation.md` | Capability discovery, adapter readiness, and failure behavior. |
| `docs/configuration.md` | Baseline-bound event and adapter configuration. |
| `docs/event_profiles.md` | Typed event configuration contract. |
| `docs/scope.md` | Declared network and file scope. |
| `docs/measurement.md` | Required pre-event baseline and claim boundary. |
| `docs/adapters.md` | Normalized adapter and browser-session boundaries. |
| `docs/browser_bridge.md` | Release-bound bridge tuple, health, restart, replacement, and rollback. |
| `docs/tools_and_wrappers.md` | Public bridge and intake command boundaries. |
| `adapters/<selected-id>/README.md` | Selected adapter event, session, modality, detail, attachment, and scoring contract. |
| `adapters/<selected-id>/adapter.json` | Selected adapter typed environment schema. |
| `adapters/<selected-id>/profile.json` | Selected adapter required capabilities and scoring modes. |
| `bin/browser-gateway-policy` | Post-baseline private gateway-policy exporter. |
| `bin/browser-health` | Linux or WSL read-only bridge health check. |
| `bin/platform-sync` | Current normalized adapter inventory sync command for an initialized workspace. |
| `bin/challenge-unlock-watch` | New and incomplete challenge intake backfill. |
| `bin/challenge-ingest` | One selected challenge intake or reviewed recovery command. |
| `AGENTS.md` | Runtime coordination invariants and state views. |
