# Canonical Rookery Sources

Paths below are relative to the installed Rookery root.

| Source | Use |
| --- | --- |
| `.env.example` | Reviewed catalog for the single operator-edited `.env`. |
| `docs/configuration.md` | Baseline-bound event and adapter configuration. |
| `docs/preparation.md` | CDP, session, and gateway readiness. |
| `docs/adapters.md` | Normalized adapter, browser session, and scope boundaries. |
| `docs/browser_bridge.md` | Release-bound bridge health and external lifecycle. |
| `docs/scope.md` | Authorized platform hosts and checked transport. |
| `docs/scoring_review.md` | Proposal, independent review, authorization, plan, execution, and reconciliation. |
| `docs/state_policy_stop.md` | Current policy and stop-generation requirements. |
| `docs/evidence_state.md` | Private evidence and scorer-response retention. |
| `adapters/<selected-id>/README.md` | Selected browser-backed adapter session, modality, detail, attachment, and reviewed submission contract. |
| `adapters/<selected-id>/adapter.json` | Selected adapter typed configuration contract. |
| `adapters/<selected-id>/profile.json` | Selected adapter capabilities and action modes. |
| `bin/browser-health` | Linux or WSL read-only bridge health check. |
| `bin/platform-sync` | Current normalized adapter inventory sync command. |
| `AGENTS.md` | Runtime coordination invariants and required state reads. |
