# Misc And Protocol Pattern Seed

## First pass

- Identify whether the challenge is really misc or a disguised web/crypto/rev/forensics task.
- Turn manual puzzles into scripts quickly.
- For remote protocols, save transcripts and build a client.

## Common lanes

- Encoding stacks: base families, hex, binary, Morse, Bacon, Braille, QR/barcode, Unicode homoglyphs.
- Esolangs: brainfuck, whitespace, Piet, Malbolge, Rockstar.
- Games: inspect save files, client JS, memory, deterministic RNG.
- Protocols: newline framing, binary structs, checksums, state machines, race/timing, auth tokens.
- Cloud/infra: exposed buckets, metadata, IAM policy puzzles, container escape clues.

## Repro standard

- Script the decode or interaction; do not rely on visual/manual-only steps unless unavoidable.
