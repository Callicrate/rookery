# Solver Workflow Pattern Seed

## Autopilot loop

Sense, route, spawn, work, verify, propose, harvest, revise.

## When stuck

Never call a challenge unknowable. Change attack style:

- naive fresh solver,
- hard investigator,
- knowledge search,
- fresh SearXNG search,
- verifier reset,
- fuzz/crack/grind,
- playful disruptor assumption break.

## Report-first workers

Each worker writes a report early, then appends commands and evidence. This prevents token loss from becoming artifact loss.

## Fast wins

Concrete artifacts beat debate. Prefer scripts, command transcripts, and reproducible checks.
